# 让小狼毫的候选窗带拼音（步骤）

## 一、装
双击本目录里的 `weasel-*.exe` → 一路下一步 → 装完托盘出现「中」字图标。
（安装需要管理员权限；装完按 Win+空格 就能切到小狼毫。）

## 二、配（3 分钟）
1. 托盘右键「中」→ 选 **用户文件夹**（会打开 %APPDATA%\Rime）。
2. 把本目录的 `weasel.custom.yaml` 复制进去。
3. 把本目录的 `custom_phrase.dict.yaml` 复制进去。
4. 托盘右键 → **重新部署**（等几秒）。

## 三、得到的效果
- 每一页候选词后面直接挂出**带声调拼音**（`spelling_hints: 4` 控制显示几个字）。
- 打字时拼音不再挤在候选窗里，而是直接显示在光标处（`inline_preedit`）。
- 打 `chongqing` 第一个候选就是「重庆」，读音被钉死为 chóng qìng。
- 竖排候选（`horizontal: false`），拼音提示看得很清楚。

## 四、想改
- 拼音提示太挤 → `weasel.custom.yaml` 里把 `spelling_hints` 调成 2 或 3，或设 0 关掉。
- 想横排 → `"style/horizontal": true`。
- 换配色 → 改 `color_scheme`（apathy / aqua / dark_temple / psionics / ink / luna）。
- 每次改完都要「重新部署」才生效。

## 五、诚实说明（做不到的部分）
- 拼音在候选**右侧**（Rime 原生能力）。要挪到候选汉字**正上方**，
  必须改 Weasel 的界面绘制源码（C++，需要 Visual Studio 生成工具）——这条路随时可以走，你说一声。
- 上屏后进入 Word/微信的仍然是纯汉字，不会带注音。要注音排版请回网页版导图/或走 Word 拼音指南。
- 想给某个词加自己的读音：在 `custom_phrase.dict.yaml` 里加一行
  `词语<TAB>pinyin<TAB>权重`，pinyin 写无声调全拼（ü 用 v），例如
  `长大	zhangda	999999`，然后重新部署。
